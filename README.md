Demand Forecasting Using Machine Learning

📌 Project Overview

Demand Forecasting is a Machine Learning project that predicts product demand using historical data and relevant factors. It helps businesses understand demand patterns, manage inventory, and make better decisions.

🎯 Objectives

- Predict future product demand.
- Analyze sales and demand patterns.
- Understand the impact of price, discounts, promotions, and weather.
- Compare different Machine Learning regression models.
- Support better inventory planning and business decisions.

📊 Dataset

The dataset contains historical demand-related information, including features such as:

- Date
- Store ID
- Product Category
- Region
- Inventory Level
- Units Sold
- Units Ordered
- Price
- Discount
- Weather Condition

The exact features depend on the dataset used in the project.
